🧮 Ícone da Calculadora de Taxas

📋 Como usar:

  1. Baixe o ícone clicando no botão acima (recomendo 1024x1024)
  2. Renomeie o arquivo para app-icon.png
  3. Substitua o arquivo em assets/app-icon.png
  4. Gere um novo build: eas build --platform android --profile preview

🎨 Design do ícone:

  • ✅ Calculadora com tela e botões funcionais
  • 💳 Cartão de crédito dourado com chip
  • % Símbolo de porcentagem para taxas
  • 💰 Símbolo de dólar para valores
  • 🎨 Cores profissionais azul e dourado
